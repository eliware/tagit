# TagIt examples

These examples demonstrate the safe project-owner handoff workflow. They use
placeholders only and contain no credentials or private machine paths.

## Contents

- [Owner workflow](owner-workflow/README.md) — safe notes, preflight, and push sequence.
- [Owner workflow directory](owner-workflow/) — the runnable example directory.
- [Plain-text workflow](owner-workflow.md) — the same sequence in a compact form.

Prerequisites: Node.js 26 or newer, Git, and a target repository with its
shared test harness. From a clean checkout, install TagIt globally or use
`npx`, then run the
commands shown by the example from a target repository root. The expected
result is a reviewed handoff with no release tag or publication performed.
All values are placeholders; never put credentials or private endpoints in an
example.
